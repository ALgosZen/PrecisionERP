# PrecisionERP Advisory & Implementation LLC

A lightweight, high-performance Single Page Application (SPA) built with **JavaScript, TypeScript, React 19, and Modern Vanilla CSS**, engineered to showcase extensive enterprise experience implementing **Core ERP systems for Government Cities, Towns, and Municipalities**.

---

## 🏛️ Government Focus & Core Modules

PrecisionERP LLC specializes in municipal government ERP implementations adhering to federal, state, and local statutory standards. The platform showcases 9 core government modules:

1. **Finance & General Ledger (GL)**: Multi-fund municipal accounting (General Fund 101, Enterprise, Debt Service, Special Revenue), real-time encumbrance control, and automated GASB 34, 87 (Leases), and 96 (SBITAs) compliance.
2. **Public Sector & Safety Payroll**: 14-day and 28-day FLSA Section 7(k) public safety overtime cycles for Police and Fire, multi-tier state retirement systems (PERS/TRS), longevity pay, and certified payroll reporting.
3. **Human Resources & Civil Service**: Civil service job classifications, union collective bargaining (MOU) rules, step-and-grade schedules, and mandatory public safety credentials (POST/CDL).
4. **Project Accounting & Capital Improvement (CIP)**: Multi-year capital infrastructure projects, federal grant drawdowns (ARPA, FEMA, DOT) under 2 CFR 200 Uniform Guidance, and contractor retainage accounting.
5. **Municipal Fleet & Telematics Management**: Tracking rolling stock (police cruisers, fire apparatus, snowplows, transit, EVs), OBD-II/J1939 telematics, work-order billing, and municipal fleet replacement indexing.
6. **City Inventory & Warehouse Management**: Parts and materials catalog for public works yards, emergency flood stockpiles, barcode cycle counting, and FIFO/weighted-average inventory valuation.
7. **Recruitment & Civil Service Merit Onboarding**: Merit-based civil service exam ranking, veteran preference score calculations, background check tracking, and digital sworn oath of office.
8. **Municipal Time & Labor Scheduling**: 24/48 Fire shift rotations, 12-hour patrol rosters, minimum staffing alarms, and FLSA 480-hour public safety comp-time banking caps.
9. **Offboarding & Public Sector Transition**: CJIS Level 4 access revocation, chain-of-custody tracking for sworn gear (weapons, badges, radios, cameras), and state retirement vesting certification.

## 🚀 Key Interactive Features

- **Live Interactive Module Simulator**: City managers and council members can interact with live simulated municipal consoles for each of the 9 modules (e.g. fund accounting ledger, FLSA 7(k) public safety overtime simulator, civil service step matrix, fleet telematics roster, and offboarding checklist).
- **Government Scope & Implementation Estimator**: Multi-step interactive calculator estimating project duration (weeks/months), phased rollout sequence, and dual-run payroll requirements based on municipality population tier and legacy system (Tyler Munis, Infor, CGI, etc.).
- **Municipal Case Studies**: Documented outcomes for real municipal transformations (City of Lakewood, Metro Regional Fire & Rescue District, County of Cumberland) with audited metrics and official testimonials.
- **The Precision 6-Stage Implementation Blueprint**: Public sector implementation methodology spanning Pre-RFP Advisory, Chart of Accounts Redesign, Data Cleansing, Dual-Run Payroll Validation, Staff Training, and 24/7 Go-Live War Room.
- **Statutory Compliance & Security Matrix**: GASB 34/54/87/96, FLSA 7(k), CJIS Level 4, 2 CFR 200 Uniform Guidance, and FedRAMP High cloud architecture.
- **Municipal Consultation & RFP Submission Modal**: Secure briefing request workflow generating unique municipal tracking reference codes.

## 🛠️ Technology Stack

- **Framework**: [Vite](https://vitejs.dev/) + [React 19](https://react.dev/)
- **Language**: TypeScript (`strict` mode with ES2023)
- **Styling**: Vanilla CSS (Custom design system with CSS custom properties, glassmorphism, responsive CSS Grid / Flexbox)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Typography**: Google Fonts (*Plus Jakarta Sans* & *JetBrains Mono*)

## 💻 Local Development

```bash
# 1. Navigate to the project directory
cd PrecisionERP

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev

# 4. Build production bundle
npm run build

# 5. Preview production build
npm run preview
```

Server will be running at `http://localhost:5173/`.
